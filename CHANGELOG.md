> **Note:** 
> 
> Some More Blocks now follows the [new numerical versioning system](https://www.minecraft.net/pt-br/article/minecraft-new-version-numbering-system) introduced by Mojang in late 2025, with one slight modification.
> 
> An additional numerical suffix has been added to identify the specific mod release. This suffix will only be incremented when multiple releases are made for the same Minecraft version, allowing individual releases to be distinguished without changing the base version.
>
> In other words, the version is: `<year>.<game drop>.<hotfix>.<mod version>`.
